# 📌 Project Overview

AI Powered Indian Wedding Cost Analytics Dashboard is an interactive data analytics and machine learning project built using **Python, Streamlit, Plotly, Scikit-Learn, and XGBoost**.

The application helps analyze Indian wedding expenses, visualize cost trends, compare wedding categories, and predict estimated wedding costs using machine learning.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/Indian-Wedding-Cost-Analytics.git
```

Move inside the folder

```bash
cd Indian-Wedding-Cost-Analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Streamlit

```bash
streamlit run app.py
```
