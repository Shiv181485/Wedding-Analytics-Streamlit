Project Report
Indian Wedding Cost Analytics Dashboard
1. Introduction

The Indian Wedding Cost Analytics Dashboard is an interactive data analytics project developed using Python, Streamlit, Plotly, Pandas, Scikit-Learn, and XGBoost. It helps users analyze wedding expenses through interactive visualizations and predictive models. The dashboard provides meaningful insights into different wedding cost categories such as decoration, photography, entertainment, clothing, and venue.

2. Problem Statement

Managing wedding expenses is challenging due to the involvement of multiple cost categories. Traditional methods such as spreadsheets are difficult to analyze and do not provide meaningful insights. This project aims to simplify wedding budget analysis through an interactive dashboard and predictive analytics.
